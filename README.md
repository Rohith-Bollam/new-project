🤖 AI Agents Suite

AI Agents Suite is a Python-based, code-driven AI project consisting of two independent LLM-powered agents.  
Each agent is executed as a standalone script and focuses on a specific task using prompt engineering and agentic design, without any web UI.

This project is intended to demonstrate core AI agent logic, task specialization, and LLM reasoning at the code level.

ℹ️ Project Scope

- This project is code-only and runs via Python scripts.
- No web interface, backend server are implemented.
- Focus is on agent behavior, prompt design, and output quality.
- Designed for learning, experimentation, and interview demonstration.
